## 🎯 Overview

VideoGyaan helps students, professionals, and lifelong learners maximize their learning efficiency from YouTube content by providing:

- **Quick Content Digestion**: Convert long videos into concise summaries
- **Interactive Learning**: Ask questions and get contextual answers
- **Multi-language Support**: Access transcripts in various languages
- **Time-Saving**: Learn key concepts without watching entire videos

**Perfect for**: Students preparing for exams, professionals staying updated with industry trends, researchers gathering information, and anyone looking to learn efficiently.

---

## 🚀 Features

### Core Functionality
- **📜 Transcript Extraction**: Automatically fetch YouTube video transcripts
- **🌐 Multi-language Support**: Choose from available transcript languages (default: English)
- **📝 AI-Powered Summarization**: Generate concise, structured summaries
- **❓ Interactive Q&A**: Ask specific questions about video content
- **📄 Full Transcript View**: Access complete video transcripts within the app

### User Experience
- **🔗 Simple URL Input**: Just paste any YouTube video URL
- **⚡ Fast Processing**: Quick transcript extraction and analysis
- **💬 Contextual Answers**: Get relevant responses based on video content
- **📱 Responsive Design**: Works seamlessly across devices

## ⚙️ Installation

Follow these steps to set up VideoGyaan locally:

### 1️⃣ Clone the Repository
```bash
[git clone https://github.com/ratnesh90859/Youtube-Video-Summery.git)](https://github.com/ratnesh90859/Youtube-Video-Summery.git)

```

### 2️⃣ Create Virtual Environment
```bash
python -m venv venv
```

### 3️⃣ Activate Virtual Environment

**Windows:**
```cmd
.\venv\Scripts\activate
```

**macOS/Linux:**
```bash
source venv/bin/activate
```

### 4️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```



### 5️⃣ Run the Application
```bash
streamlit run app.py
```

The application will be available at `http://localhost:8501`

## 🎮 Usage

### Getting Started
1. **Launch the App**: Open your browser to `http://localhost:8501`
2. **Enter YouTube URL**: Paste any YouTube video URL in the input field
3. **Select Language**: Choose your preferred transcript language (optional)
4. **Extract Transcript**: Click to fetch the video transcript
5. **Generate Summary**: Get an AI-powered summary of the content
6. **Ask Questions**: Use the Q&A feature to dive deeper into specific topics

### Supported Video Types
- Educational content
- Tutorials and how-to videos
- Lectures and presentations
- Documentaries
- News and analysis videos

### Tips for Best Results
- Ensure videos have available transcripts
- Use specific questions for better Q&A responses
- Try different languages if English transcripts aren't available
