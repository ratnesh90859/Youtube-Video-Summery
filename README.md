VideoGyaan is a Streamlit-powered web application that helps you quickly understand YouTube videos by:
 Extracting video transcripts
 Summarizing content into concise notes
 Allowing Q&A on the video topic

This app is perfect for students, professionals, or anyone who wants to save time and learn efficiently from YouTube.


Features

 Enter any YouTube video URL.

 Choose transcript language (default: en).

 Get the full transcript inside the app.

 Generate an AI-powered summary.

Ask questions about the video and get contextual answers.
